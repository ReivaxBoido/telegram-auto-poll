# Incidents

Store blameless postmortems here as `YYYY-MM-DD-<short-title>.md`.

Each postmortem should include:

- Summary and severity
- Timeline (UTC)
- Impact (chats, polls, data, duration)
- Root cause
- Detection
- Response and recovery
- What went well / what did not
- Action items with owners and due dates
- Links to logs, PRs, and ADRs

Do not include bot tokens, private chat contents, or personal data. Redact chat IDs when they are not
necessary to the narrative.
